# 阿姆罗出击 · Gundam Minigame

一个基于 HTML Canvas 和原生 JavaScript 的 SD 高达太空射击小游戏。驾驶 RX-78 突围，击败大扎姆后进入白色基地换装 Hi-ν 高达，再迎战乍得·多加和沙扎比。

无需安装依赖或构建；画面、战斗、界面和合成音乐都在浏览器中运行。

## 开始游戏

下载并解压完整项目，保留 `index.html` 和 `assets/` 的相对位置。

推荐在项目目录启动静态服务（需要 Python 3）：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765/>，点击“开始行动”。也可直接双击 `index.html`，但浏览器对本地文件的存储策略可能不同，排行榜建议通过固定地址访问。

音乐在点击开始后播放，可用底部音乐按钮关闭。切换到其他窗口或标签页时会自动暂停。

## 操作

| 操作 | 按键 / 方式 |
| --- | --- |
| 移动 | 方向键、WASD，或在战场内拖动 |
| 射击 | 自动射击 |
| 光束军刀 | Q，向前方小范围扇形斩击，冷却 1 秒 |
| 全弹发射 | E，击破 10 台普通敌机蓄满后使用 |
| 暂停 / 继续 | 空格或右上角暂停按钮 |
| 音乐开关 | 底部音乐按钮 |
| 查看成绩 | 底部“排行榜”按钮 |

## 玩法

- **单机体作战**：RX-78 初始 100 HP。绿色维修门通过碰撞恢复生命，红色门会扣血。
- **换装**：击败半场 Boss 大扎姆后，继续推进约 10 秒，白色基地从左、中、右随机航道出现。碰撞绿色机库入口换装 Hi-ν，HP 上限提升至 150，并获得 50 HP、双浮游炮和周期性 I 立场。换装后攻击力提升 5%，背景音乐切换为更快的 8-bit 曲目。
- **Hi-ν 防御**：每 8 秒自动展开 0.5 秒无敌的三角形 I 立场。
- **友军**：换装后，普通战斗每 15 秒加入一台自主移动的 Zeta Plus，以短激光支援；承受 7 次有效攻击后爆炸退场。Boss 阶段不再刷新新友军。
- **敌机**：包含扎古系列、兹达、勇士系列、大魔、京宝梵、强人、吉翁号和吉拉多加等外观及多种攻击模式。
- **Boss 战**：大扎姆使用散弹、粗激光和扇形近战；乍得·多加使用短激光和浮游炮，交战 8 秒后沙扎比登场，两者可以同场作战。沙扎比具有定向短激光、浮游炮、中央高能激光、周期性 I 立场及带预警的近身光束剑。
- **战斗演出**：Boss 对话过场、爆炸退场、太空背景与 Axis 场景、光束剑拖尾和全弹发射特效。

### 击破掉落

只有击败屏幕内的普通敌机才会随机掉落物品，需要移动碰撞拾取。

| 掉落 | 每次击破的概率 | 效果 |
| --- | --- | --- |
| 弹药 | 合计 15% | 追踪弹、散弹、持续激光等概率随机一种；持续 15 秒后恢复光束步枪 |
| I 立场 | 8% | 无敌 5 秒 |
| 能量罐 | 8% | 移动速度提高 30%，持续 15 秒 |
| 无掉落 | 69% | — |

同一敌机最多掉落一件物品。再次拾取会更新对应效果或持续时间。

### 排行榜

通关或失败时记录本局非零分数，仅保留最高 10 条，显示击破数、用时、结果和日期。每局只记录一次；暂停或未结束的对局不会写入成绩。

数据保存在当前浏览器的 `localStorage`，键为 `neon-column:scores:v1`。排行榜属于本机记录，不是联网排行榜；更换浏览器、访问地址或清除网站数据后不会共享原记录。如果浏览器禁止持久存储，则仅在当前页面会话内保留。查看排行榜会暂停游戏，关闭后点击继续恢复。

## 检查与开发

需要 Node.js；当前版本在 Node.js 26 下验证通过。在项目目录执行：

```sh
node check.cjs
```

检查覆盖移动与碰撞、武器和掉落、伤害与防御、Boss 过场及同场逻辑、换装、友军、音乐切换和排行榜等。测试使用模拟的浏览器环境，不会读写真实浏览器的成绩；画面与声音效果仍需在浏览器中体验。

主要修改入口都在 `index.html`：

| 功能 | 入口 |
| --- | --- |
| 主循环与关卡推进 | `update`、`wave` |
| 武器及掉落 | `shoot`、`dropWeapon`、`damage` |
| 沙扎比近战参数 | `SAZABI_SABER`、`updateSazabiSaber` |
| 乍得·多加攻击 | `updateJagd` |
| 精灵帧与渲染 | `REFERENCE_FRAMES`、`drawReferenceUnit` |
| 排行榜 | `normalizeScores`、`readScores`、`recordScore` |

素材使用相对路径加载，部署时将 `index.html` 和整个 `assets/` 目录放在同一级即可。可使用普通静态网站服务；本项目没有后端、账户服务或安装步骤。
